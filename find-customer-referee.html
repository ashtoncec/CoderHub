Find Customer Referee

Filter rows while keeping customers with no referee.

Easy50 XP

Problem Statement

Return the names of customers who have no referee or whose referee is someone other than customer 2. The names may appear in any order.

Customer schema
ColumnType
idint
namevarchar
referee_idint

id is the primary key. Each row stores a customer's name and the ID of whoever referred them. A NULL referee means no one referred that customer.

Example input: Customer
idnamereferee_id
1WillNULL
2JaneNULL
3Alex2
4BillNULL
5Zack1
6Mark2
Expected output
name
Will
Jane
Bill
Zack

Alex and Mark were referred by customer 2, so exclude them. Keep Zack and the three customers with no referee.

Open problem 584 on LeetCode

SQL Solution

Select the name column. Use OR to keep either a referee other than 2 or a missing referee. A comparison with NULL is unknown, so != 2 alone would drop customers with no referee.

Why this query works

SELECT name
FROM Customer
WHERE referee_id != 2 OR referee_id IS NULL;
