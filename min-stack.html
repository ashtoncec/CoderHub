Min Stack

Implement a stack with push, pop, top, and minimum retrieval.

100 XP Medium

Problem Statement

Implement a MinStack with these operations, each in O(1) time:

  • MinStack(): create an empty stack.
  • push(val): add a value.
  • pop(): remove the top value.
  • top(): return the top value.
  • getMin(): return the smallest value currently stored.

Example

minStack = MinStack()
minStack.push(-2)
minStack.push(0)
minStack.push(-3)
minStack.getMin()  # -3
minStack.pop()
minStack.top()     # 0
minStack.getMin()  # -2

Constraints

Values range from -2³¹ to 2³¹ - 1. There are at most 30,000 method calls. pop, top, and getMin are called only when the stack is nonempty.

Q&A Mode

Why this solution works

class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val: int) -> None:
        self.stack.append(val)

        if self.min_stack:
            val = min(val, self.min_stack[-1])

        self.min_stack.append(val)

    def pop(self) -> None:
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]
