Replace Employee ID With The Unique Identifier

Keep every employee, even when their unique identifier is missing.

Easy50 XP

Show each employee’s unique identifier and name. When no identifier matches, return NULL for unique_id. Any result order is accepted.

Alice and Bob have no matching identifier, so their unique_id is NULL. All five employees remain in the output.

SQL Solution

Why this query works

SELECT u.unique_id, e.name
FROM Employees AS e
LEFT JOIN EmployeeUNI AS u
ON e.id = u.id;
