Longest Substring Without Repeating Characters

Grow the window to the right, and whenever a duplicate appears, shrink from the left until the window is clean again.

Given a string s, find the length of the longest substring without duplicate characters.

A substring is a contiguous sequence of characters within a string.

Example 1

Input: s = "zxyzxyz"

Output: 3

Explanation: The string "xyz" is the longest without duplicate characters.

Example 2

Input: s = "xxxx"

Output: 1

Constraints

0 <= s.length <= 50,000

s may consist of printable ASCII characters.

Python Solution

Hash Set

Use a set to represent the current window. If the right character is already inside, keep removing from the left until that duplicate is gone.

Time: O(n) Space: O(n)

Q&A Mode

Why this solution works

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        charSet = set()
        l = 0
        res = 0

        for r in range(len(s)):
            while s[r] in charSet:
                charSet.remove(s[l])
                l += 1
            charSet.add(s[r])
            res = max(res, r - l + 1)
        return res
