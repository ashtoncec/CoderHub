Daily Temperatures

Find how many days until a strictly warmer temperature.

100 XP Medium

Problem Statement

Given the daily temperatures, return an array containing the number of days until the next strictly warmer day for each position. Use 0 when no warmer day follows.

Example 1

Input: temperatures = [73,74,75,71,69,72,76,73]

Output: [1,1,4,2,1,1,0,0]

Example 2

Input: temperatures = [30,40,50,60]

Output: [1,1,1,0]

Example 3

Input: temperatures = [30,60,90]

Output: [1,1,0]

Constraints

1 ≤ temperatures.length ≤ 100,000

30 ≤ temperatures[i] ≤ 100

Why this solution works

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        answer = [0] * len(temperatures)
        stack = []

        for i, temp in enumerate(temperatures):
            while stack and temp > temperatures[stack[-1]]:
                prev = stack.pop()
                answer[prev] = i - prev

            stack.append(i)

        return answer
