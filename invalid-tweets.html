Invalid Tweets

Filter tweets by the number of characters in their content.

Easy50 XP

Problem Statement

Return the IDs of tweets whose content contains more than 15 characters. The output can be in any order.

Tweets schema
ColumnType
tweet_idint
contentvarchar

tweet_id is the primary key. Content contains alphanumeric characters, spaces, and exclamation marks.

Example input: Tweets
tweet_idcontent
1Let us Code
2More than fifteen chars are here!
Expected output
tweet_id
2

The first tweet contains 11 characters and is valid. The second contains 33 and is invalid. A tweet with exactly 15 characters is still valid.

Open problem 1683 on LeetCode

SQL Solution

CHAR_LENGTH counts characters, including spaces and punctuation. Keep only lengths greater than 15, then return tweet_id.

Why this query works

SELECT tweet_id
FROM Tweets
WHERE CHAR_LENGTH(content) > 15;
