Given an array of integers nums and an integer target, return the indices i and j such that nums[i] + nums[j] == target and i != j.

You may assume that every input has exactly one pair of indices i and j that satisfy the condition. Return the answer with the smaller index first.

Example 1

Input: nums = [3,4,5,6], target = 7

Output: [0,1]

Example 2

Input: nums = [4,5,6], target = 10

Output: [0,2]

Example 3

Input: nums = [5,5], target = 10

Output: [0,1]

Python Solution

Hash Map

As you scan the array, store each number’s index. For each element, check whether its complement has already been seen.

Time: O(n) Space: O(n)

Q&A Mode

Why this solution works

from typing import List


class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        prevMap = {}

        for i, n in enumerate(nums):
            diff = target - n
            if diff in prevMap:
                return [prevMap[diff], i]
            prevMap[n] = i
