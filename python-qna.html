Reference Guide

Python Q&A

A big interview-prep cheat sheet for Python syntax, built-ins, and data-structure helpers you keep seeing on LeetCode. Each item has a short definition and a quick example.

Core Containers

The main data structures

These are the first tools you reach for when solving array, hashing, and graph-style questions.

list

An ordered, mutable sequence. Great for arrays, stacks, dynamic results, and indexed access.

nums = [3, 1, 4]
nums.append(9)

tuple

An ordered, immutable sequence. Useful when you need a fixed pair or a hashable key.

point = (row, col)
seen.add(point)

set

An unordered collection of unique values. Best for fast membership checks and deduping.

seen = set(nums)
if target in seen:
    pass

dict

A hash map from key to value. This is one of the most common LeetCode tools.

index = {}
index[nums[i]] = i

str

An immutable string type. Handy for parsing, scanning, building keys, and character checks.

word = "neetcode"
first = word[0]

bool

Stores True or False. Usually used for flags, visited state, or yes/no answers.

found = False
if num == target:
    found = True

Collections Helpers

Special containers from the standard library

These show up constantly in clean Python interview solutions.

defaultdict

A dictionary that creates a default value automatically when a key is first accessed.

from collections import defaultdict
groups = defaultdict(list)
groups[key].append(word)

Counter

Counts how many times each item appears. Great for frequency maps.

from collections import Counter
count = Counter(nums)

deque

A double-ended queue with fast pops and appends from both sides. Perfect for BFS.

from collections import deque
queue = deque([start])
node = queue.popleft()

heapq

Python’s min-heap utilities. Use it for top-k, scheduling, or greedy problems.

import heapq
heapq.heappush(heap, value)
smallest = heapq.heappop(heap)

setdefault

Gets a key’s value if it exists, otherwise inserts a default and returns that.

graph.setdefault(src, []).append(dst)

get

Safely reads a dictionary key and gives a fallback value if the key is missing.

count[num] = 1 + count.get(num, 0)

Loops & Traversal

Ways to move through data

These patterns help you walk arrays, strings, matrices, and maps more cleanly.

range()

Creates a sequence of numbers, most often used in for-loops.

for i in range(len(nums)):
    print(i)

enumerate()

Loops through items while also giving you the index.

for i, num in enumerate(nums):
    print(i, num)

zip()

Pairs elements from multiple iterables together.

for a, b in zip(nums1, nums2):
    print(a + b)

reversed()

Iterates through a sequence in reverse order without changing the original data.

for ch in reversed(word):
    print(ch)

items()

Loops through both keys and values in a dictionary.

for key, value in count.items():
    print(key, value)

values()

Returns just the values from a dictionary.

answer = max(count.values())

Sorting & Selection

Ordering data the Python way

Sorting syntax looks simple, but the helper arguments are where people usually get tripped up.

sorted()

Returns a new sorted list from any iterable.

ordered = sorted(nums)

list.sort()

Sorts a list in place instead of making a new list.

nums.sort()

key=

Lets you control what value Python should sort by.

words.sort(key=len)

lambda

A short anonymous function, often used with sorting or mapping.

pairs.sort(key=lambda pair: pair[1])

reverse=True

Sorts in descending order instead of ascending order.

nums.sort(reverse=True)

max(..., key=...)

Finds the largest item using a custom comparison value.

best = max(words, key=len)

Strings & Characters

Small syntax that shows up all the time

These character-level tools are huge for palindrome, parsing, and hash-map problems.

ord()

Turns a character into its integer Unicode value. Super common for frequency arrays.

idx = ord(c) - ord("a")

chr()

Turns an integer Unicode value back into a character.

letter = chr(ord("a") + 2)

split()

Breaks a string into pieces and returns them as a list.

parts = "a,b,c".split(",")

"".join(...)

Combines an iterable of strings into one string.

word = "".join(chars)

lower()

Converts a string to lowercase, which is helpful for case-insensitive comparisons.

if s[left].lower() == s[right].lower():
    pass

isalnum()

Checks whether a character is a letter or number.

if ch.isalnum():
    filtered.append(ch)

Indexing & Slicing

Reading and cutting sequences

A lot of LeetCode code is really just careful index math with clean Python syntax.

nums[i]

Reads the item at index i.

value = nums[i]

nums[-1]

Negative indices count from the end. -1 means the last element.

last = nums[-1]

nums[a:b]

Takes a slice from index a up to but not including index b.

window = nums[left:right]

nums[::-1]

Creates a reversed copy of a sequence.

rev = s[::-1]

len()

Returns how many items are in a sequence or collection.

n = len(nums)

in

Checks whether a value exists inside a container.

if target in seen:
    return True

Comprehensions

Compact ways to build containers

These can make Python solutions look much shorter, but only when you know what they are doing.

[x for x in nums]

A list comprehension builds a list in one expression.

squares = [x * x for x in nums]

{x for x in nums}

A set comprehension builds a set in one expression.

unique = {x for x in nums}

{k: v for ...}

A dictionary comprehension builds a dictionary in one expression.

pos = {num: i for i, num in enumerate(nums)}

if inside a comprehension

Filters the values that should be included.

evens = [x for x in nums if x % 2 == 0]

Nested comprehension

Builds values from nested loops. Powerful, but easy to overcomplicate.

pairs = [(r, c) for r in range(rows) for c in range(cols)]

[[] for _ in range(n)]

The safe way to build many separate inner lists.

freq = [[] for _ in range(len(nums) + 1)]

Math & Logic Helpers

Useful built-ins for cleaner code

These aren’t flashy, but they simplify a lot of interview solutions.

sum()

Adds up values from an iterable.

total = sum(nums)

min() and max()

Return the smallest or largest value.

smallest = min(nums)
largest = max(nums)

abs()

Returns the absolute value of a number.

distance = abs(left - right)

any()

Returns True if at least one item in an iterable is truthy.

if any(x < 0 for x in nums):
    pass

all()

Returns True only if every item in an iterable is truthy.

if all(ch.isdigit() for ch in s):
    pass

divmod()

Returns quotient and remainder at the same time.

q, r = divmod(num, 2)

Mutation Patterns

How Python updates containers

These are the little operations you use repeatedly while building a result.

append()

Adds one item to the end of a list.

res.append(num)

pop()

Removes and returns an item, usually from the end of a list or a key from a dictionary.

top = stack.pop()

add()

Adds one item to a set.

seen.add(num)

remove() vs discard()

Both remove from a set, but remove() errors if missing while discard() does not.

seen.discard(num)

update()

Adds multiple items into a set or dictionary at once.

seen.update([1, 2, 3])

Swap syntax

Python can swap values in one line without a temporary variable.

nums[left], nums[right] = nums[right], nums[left]
