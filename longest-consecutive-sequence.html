Longest Consecutive Sequence

The trick is to only start counting when you’re at the beginning of a sequence, not from every number.

Given an array of integers nums, return the length of the longest consecutive sequence of elements that can be formed.

A consecutive sequence is a sequence of elements in which each element is exactly 1 greater than the previous element. The elements do not have to be consecutive in the original array.

You must write an algorithm that runs in O(n) time.

Example 1

Input: nums = [2,20,4,10,3,4,5]

Output: 4

Explanation: The longest consecutive sequence is [2, 3, 4, 5].

Example 2

Input: nums = [0,3,2,5,4,6,1,1]

Output: 7

Python Solution

Hash Set

Put everything in a set, only begin from numbers that do not have a predecessor, then walk forward to measure that streak.

Time: O(n) Space: O(n)

Q&A Mode

Why this solution works

from typing import List


class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        numSet = set(nums)
        longest = 0

        for num in numSet:
            if (num - 1) not in numSet:
                length = 1
                while (num + length) in numSet:
                    length += 1
                longest = max(length, longest)
        return longest
